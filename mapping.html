Mapping ระบบ

ของที่มีอยู่ตอนนี้ อยู่ตรงไหนในระบบใหม่

Autopost, Chatbot, Matching และไฟล์ Excel เดิม ไม่ต้องทิ้ง แต่ต้องย้ายให้เข้า 4 ก้อนงานใหม่ และเติมแกนกลางให้ทำงานร่วมกัน

1

รับงาน + ทำสื่อ

ใช้รับใบขอ สร้างโพสต์ รับ Lead และเตรียมข้อมูลเข้าระบบ

2

เดินงาน

ใช้ส่งงานต่อ จับคู่คนกับงาน โทร/คัดกรอง และติดตามสถานะ

3

ตรวจ + อนุมัติ

ใช้ตรวจคุณภาพ อนุมัติโพสต์ ส่งลูกค้า และจัดการ Reject

4

ปิดงาน + ส่งต่อ

ใช้แจ้งเริ่มงาน ปิดใบขอ Follow-up และหาคนแทน

Mapping ของที่มีอยู่
Autopostก้อน 1
ใช้: โพสต์งานตาม Facebook Group
ต้องเพิ่ม: Approval ก่อนโพสต์ · Post Tracking · รูป/วิดีโอ · Campaign ID
ใบงาน Excelก้อน 1
ใช้: ดูรายละเอียดงาน / Tracking ใบขอ
ต้องเพิ่ม: เปลี่ยนเป็น Request Queue
Chatbotก้อน 1·2
ใช้: รับ Lead, ตอบแชท, พาคนไปสมัครงาน
ต้องเพิ่ม: Facebook/TikTok · Lead Queue · Lead ID · ส่ง Lead เข้า Matching
Matchingก้อน 2
ใช้: Match คนกับงาน, จัดลำดับผู้สมัคร, จัด WL, Job Page
ต้องเพิ่ม: Queue กลาง · Status กลาง · Match Reason · SLA
งานของแต่ละคน Excelก้อน 2
ใช้: ดูว่าแต่ละคนต้องทำอะไร
ต้องเพิ่ม: เปลี่ยนเป็น Task Queue
Matchingก้อน 3
ใช้: ช่วยเลือกคนที่เหมาะก่อนส่งลูกค้า
ต้องเพิ่ม: Approval Queue · Candidate Packet · Reject Reason
Matchingก้อน 4
ใช้: ยืนยันลงงาน, หาคนแทน, คาดการณ์ลาออก, Dashboard
ต้องเพิ่ม: Close Case · Replacement Queue · Follow-up Status
หาคนแทน Excelก้อน 4
ใช้: ดูคนว่างงาน / หาคนแทน
ต้องเพิ่ม: เปลี่ยนเป็น Replacement Queue
สถานะ: ยังใช้อยู่ได้ — เป็นฐานข้อมูลเก่า ใช้ชั่วคราวระหว่างรอเปลี่ยน

ต้องเพิ่มหลัก ๆ แค่นี้ก่อน

Case ID / Request ID กลาง Queue กลาง Status กลาง Approval Queue Exception Queue Dashboard กลาง

Autopost, Chatbot และ Matching ไม่ใช่ระบบที่ต้องทิ้ง แต่ต้องถูกจัดให้อยู่ใน 4 ก้อนงานใหม่ โดยมี Case ID, Queue, Status, Approval, Exception และ Dashboard เป็นแกนกลางเชื่อมทุกระบบเข้าด้วยกัน
